# 문제 해결 기록

## 1. secrets.toml 파일 위치가 잘못됨 (2026-11-25)

- **증상:** 테스트 앱 실행 시 "API 키를 찾지 못했습니다" 안내가 뜸.
- **원인:** 키 파일이 `.streamlit/secrets.toml`이 아니라 프로젝트 맨 위에
  `.streamlitsecrets.toml`이라는 이름으로 저장되어 있었다 (폴더 구분자 `/`가 빠짐).
  Streamlit은 `.streamlit` 폴더 안의 `secrets.toml`만 읽는다.
- **해결:** 파일을 `.streamlit/secrets.toml`로 옮겼다. 키가 실수로 커밋되지 않도록
  `.gitignore`에 두 이름을 모두 적고, `git check-ignore -v`로 제외 여부를 확인했다.
- **결과:** 옮긴 뒤 "API 키를 불러왔습니다"가 표시되고, 서울대입구역 → 강남역 조회가
  정상 동작했다 (14분, 환승 0회, 1,550원, SUBWAY, 경로 14개 중 최단).

## 2. 공공데이터 역 좌표 오류 (2026-11-25)

- **증상:** 전처리 중 "같은 노선에서 50m 안에 붙어 있는 서로 다른 역"을 찾아보니
  5호선 마곡–발산(7m), 4호선 신용산–이촌(14m)이 나왔다. 실제로는 각각 약 1km 떨어진 역이다.
- **원인:** 원본(국가철도공단 역사정보)에서 마곡에 발산의 좌표, 이촌에 신용산의 좌표가 잘못 들어가 있었다.
- **해결:** 한국어 위키백과의 좌표로 교체하고, `prepare_data.py`의 `FIX_COORDS`에 출처와 함께 적었다.
  (카카오 API 결과는 파일로 저장하면 안 되므로 카카오로 고치지 않았다.)

## 3. 같은 역인데 이름이 달라 합쳐지지 않음 / 다른 역인데 이름이 같음 (2026-11-25)

- **증상:** 환승역을 이름으로 합쳤더니 "신도림"과 "신도림역"이 따로 남았다.
  또 "역"을 떼고 나니 5호선 양평(서울)과 경의중앙선 양평(양평군, 약 54km 거리)이 한 역으로 합쳐질 뻔했다.
- **원인:** 한국철도공사 노선은 역 이름 뒤에 '역'이 붙어 있다. 7호선 '이수'와 4호선 '총신대입구(이수)'처럼
  노선마다 이름이 다른 역도 있다.
- **해결:** 괄호와 끝의 '역'을 떼고, 별칭은 `NAME_ALIASES`로 통일했다.
  이름이 같아도 1km 넘게 떨어지면 `양평(경의중앙선)`처럼 노선 이름을 붙여 다른 역으로 구분했다.

## 4. 경의중앙선 역이 '1호선'으로 표시됨 (2026-11-25)

- **증상:** 이촌·서빙고·왕십리 등이 "1호선"으로 표시되었다.
- **원인:** 원본은 노선을 선로 기준(경원선)으로 적는데, 경원선 용산~왕십리 구간(역번호 1003~1013)에는
  실제로 경의중앙선 전철이 다닌다.
- **해결:** `fix_gyeongwon_line()`에서 이 구간만 경의중앙선으로 바꾼 뒤 나머지 경원선을 1호선으로 바꿨다.
